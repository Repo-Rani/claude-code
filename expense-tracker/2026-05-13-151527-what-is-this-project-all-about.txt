● The repository is a tiny Flask‑based personal‑finance tracker.

  - Core – app.py creates the Flask app and defines the main routes (landing
  page, registration, login and placeholder routes for logout, profile, expense
  CRUD, etc.).
  - Database layer – database/db.py is a stub that will eventually hold SQLite
  helpers (get_db(), init_db(), seed_db()).
  - UI – HTML templates live in templates/ (base.html, landing.html,
  register.html, login.html) and are rendered with Jinja2. Static assets (CSS in
   static/css/style.css and a placeholder JS file) support the front‑end.
  - Setup – Dependencies are listed in requirements.txt; the app runs with
  python app.py (debug mode on port 5001).

  Overall, this project is a step‑by‑step tutorial‑style web app that will let a
   user register, log in, and later manage expense records backed by an SQLite
  database.
