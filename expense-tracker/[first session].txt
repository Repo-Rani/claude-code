● Project Overview

  - Purpose – A simple personal‑finance tracker built with Flask. It provides a
  web UI for users to register, log in, and (later) manage expenses.
  - Key Components
    a. app.py – Creates the Flask app (app = Flask(__name__)) and defines all
  route handlers. Current routes include:
        - Landing page (/)
      - Registration (/register)
      - Login (/login)
      - Place‑holder routes (/logout, /profile, /expenses/*) that will be
  fleshed out in later steps.
    b. database/db.py – Stub for SQLite helpers. When implemented it will
  expose:
        - get_db() – returns a connection with row‑factory and foreign‑key
  support.
      - init_db() – creates tables if they don’t exist.
      - seed_db() – inserts sample data for local development.
    c. Templates (templates/) – Jinja2 HTML files extending base.html. Important
   pages:
        - landing.html – marketing/home page.
      - register.html – user registration form.
      - login.html – login form.
    d. Static assets (static/)
        - css/style.css – design tokens and layout.
      - js/main.js – empty placeholder for future client‑side scripts.
  - Project Layout
  expense-tracker/
  ├─ app.py                 # Flask app & routes
  ├─ database/
  │  └─ db.py              # SQLite helper (to be implemented)
  ├─ templates/
  │  ├─ base.html
  │  ├─ landing.html
  │  ├─ register.html
  │  └─ login.html
  ├─ static/
  │  ├─ css/style.css
  │  └─ js/main.js
  ├─ requirements.txt      # Python dependencies
  └─ .gitignore            # e.g. DB file, env, caches

  - Development Workflow
    a. Install dependencies
  python -m pip install -r requirements.txt
    b. Run the app (debug mode, port 5001)
  python app.py
    c. Run the test suite
  pytest
    d. Optional lint/format
  pip install flake8 black
  flake8 .
  black .
  - Next Steps in the Tutorial
    - Implement the SQLite helper in database/db.py.
    - Add CRUD routes for expense management under /expenses/*.
    - Extend the UI to display and edit expenses.
    - Secure the app (session secret, password hashing, etc.).
  - Notes
    - The repository isn’t a Git repo yet, so Git‑related commands will fail
  until it’s initialized.
    - The SQLite file (e.g., expense_tracker.db) should be listed in .gitignore
  to avoid committing local data.
    - Flask’s built‑in static file serving works out‑of‑the‑box; no extra
  configuration is required.
